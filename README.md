# 올팍 길잡이 (시제품)

한국체육산업개발(주) 「2026년도 공공데이터 활용 경진대회」 응모용 시제품. 올림픽공원 방문 전 질문에 FAQ 원문 근거를 붙여 답하고, 입출차 기록으로 요일·시각별 주차 혼잡을 예보한다. 서버·API 키 없이 정적 파일만으로 동작한다.

## 실행

```bash
python3 scripts/analyze_parking.py   # site/data/parking.json
python3 scripts/build_data.py        # site/data/faq.json, events.json
node tests/test_search.mjs           # 검색·예보·요금 검사
cd site && python3 -m http.server 8765   # http://127.0.0.1:8765
```

`data/raw`(원본 cp949)와 `data/utf8`은 공공데이터포털에서 2026-11-06 내려받은 사본이다.

## 한계

- 입출차 자료가 2024년 7월 한 달뿐이다. 월 보정은 하루 시각 분포가 달마다 같다고 보고 크기만 바꾼 추정이다. 실시간 연계 API(한국문화정보원 「올림픽공원 2025 차량입출차, 공연, 날씨정보 등 연계 데이터」)는 인증키가 필요해 아직 붙이지 않았다.
- 영문 공연정보의 '공연일자'는 여러 공연이 같은 날짜로 묶여 있어 실제 공연일인지 기관 확인이 필요하다.
- 혼잡 단계 기준(전체 면수 대비 40%·60%)은 2024-07 평일·평소 주말·급증 주말 최대치를 가르도록 정한 값이며, 방문객이 느끼는 혼잡과 맞는지는 아직 검증하지 않았다.
